# 《魔兽世界》："无限"（World of Warcraft: Forever）开荒资料库

> Classic+ 永久分支 · 等级上限锁 60 · 无飞行 · 无等级缩放 · 规则集取代服务器
> 国服上线 **2026-11-05 约 07:00**（= 2026-11-04 15:00 PST）

## 一、这到底是什么

《无限》不是怀旧服复刻，而是暴雪在 **Classic+** 路线上新开的**永久 60 级分支**：

- **永久**：不删档、不转换，账号资产长期保留（与"赛季服"相反）
- **等级锁 60**：没有满级之后继续升的天数系统
- **无飞行**：40 级才有地面坐骑，地图移动成本极高 —— 这是所有路线计算的起点
- **无等级缩放 / 无直升**：1-60 必须实打实练
- **规则集（Rule Set）取代服务器**：同规则集 + 同阵营才能组队
- **无个人拾取**：团本掉落所有人都能拿，也意味着"带老板"彻底归零

## 三、只有 5 件事要在上线前做（其余一律上线后再弄）

1. **决定规则集**：同规则集 + 同阵营才能组队，这是选错回不了头的决定（见「开局行动手册」）
2. **备 3 组完整角色名**：名 + 姓双字段，避开随机名生成器（9-29 误封事故曾导致资格被永撤）
3. **下载客户端**：战网桌面应用 → 左上"偏好" → 《无限》，或官网绿色完整版
4. **买不买礼包**：¥218 英雄礼包不含 Beta 资格、含名称预留；¥388 天裔史诗含国服 Beta
5. **定职业与专业**：先定这两项，其余（键位、插件、宏）上线前 10 分钟就够

> 硬件：能跑 12.x 正式服的机器即可，本库不单列门槛。
