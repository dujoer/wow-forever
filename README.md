# 《魔兽世界》："无限"（World of Warcraft: Forever）开玩准备项目

> 目标：在 **2026 年 11 月 5 日（国服全球同步上线）** 顺利开玩《魔兽世界》："无限"。
> 本文档为个人准备台账，所有信息来自 2026-09-18 当日的官方与权威媒体公开资料，临近上线请以官网为准。

---

## 一、这到底是什么

- **官方中文名**：《魔兽世界》："无限"（部分媒体译为"永恒"；英文 **World of Warcraft: Forever**）。
- **定位**：暴雪在 2026 暴雪嘉年华公布的 **"Classic+（经典+）"永久分支**，与 **正式服（Modern）**、**怀旧服（Classic）** 并行存在，是"第三条路"。**长线运营、非赛季制**。
- **核心形态**：回到经过全面画面升级的**原版艾泽拉斯**，等级上限**锁定 60 级**，采用**横向扩展**（加区域/任务/副本/职业玩法/装备，而非提升等级上限）。剧情设定在 2004 原版第一年附近的分叉平行世界线。
- **去服务器化**：不再有传统独立服务器，改为选择**规则集**——普通 / PvP / 角色扮演 / 专家模式（Hardcore，一命）。
- **画面**：更新光照、全局光照、水体、实时阴影；可选 **HD/SD 角色模型**、经典动画还原、**官方手柄支持**。

## 三、开玩前准备清单（按优先级）

### A. 账号与准入（最优先，建议在 10 月前完成）
- [ ] **确认/找回暴雪战网账号**：国服账号由网易运营，官网首页有"账号找回"（实名/账号两种方式，约 3 分钟）。
- [ ] **确保有《魔兽世界》游戏时间（月卡）**：基础版"无限"已含在月卡内；若你已有正式服月卡，基础准入已满足。
- [ ] **决定是否购买礼包**（想玩天裔/进 Beta/抢名必买）：
  - **天裔英雄礼包 ¥218**：天裔种族 + 泽风岛起始 + 名称预留资格（11-03~11-04）+ 幻化/坐骑/玩具/战袍 + 1 个邀请好友资格。
  - **天裔史诗礼包 ¥388**：英雄礼包全部内容 + **国服 Beta 资格（10-06 删档）** + **30 天游戏时间（11-05 到账）** + 更多宠物/装饰 + 3 个邀请好友资格。
- [ ] **官网预约**（免费）：上线后首个角色背包送 **4 格背包**。务必做。
- [ ] **准备 3 个备选角色名**：名称先到先得，11-03~11-04 预留期可抢注。

### B. 客户端与硬件（建议 10 月 6 日 Beta 前就绪）
- [ ] 安装/更新 **战网桌面应用**（Battle.net）。
- [ ] 安装/更新 **《魔兽世界》客户端**（"无限"与正式服大概率共用客户端），预留 **≥128GB SSD** 空间（官方明确 HDD 会影响体验）。
- [ ] **核对配置**（见下"配置要求"小节；最低可玩，推荐更流畅）。
- [ ] 决定 **视觉预设**（HD 或 SD 模型、是否开经典动画）与 **输入方式**（键鼠 / 手柄）。

### C. 角色规划（上线前定好，避免抢注时纠结）
- [ ] 阵营：联盟 / 部落。
- [ ] 种族 + 职业：是否选新组合（矮人萨满、被遗忘者圣骑士等）或天裔（需礼包）。
- [ ] 规则集：普通 / PvP / 角色扮演 / 专家模式（一命，慎选）。
- [ ] 专业路线：专业已重构（600+ 新配方），提前想好采集/制造搭配。
- [ ] 关注全职业**天赋树深度重做**信息（保留经典结构，但专精重做）。

### D. 知识储备（可选但推荐）
- [ ] 因是 60 级封顶的 Classic+，建议温习**原版/经典怀旧服**的练级路线、职业手法、常用插件。
- [ ] 观看官方 **深度解析座谈会（09-13/09-14）** 回放，了解系统与玩法。
- [ ] 提前物色**公会/社群**，上线不孤单。

### E. Beta 体验（10-06 ~ 10-27，买了史诗礼包才有）
- [ ] 进国服删档 Beta（等级上限 30），试玩目标职业、熟悉系统、提反馈。
- [ ] **注意：删档**，不要过度投入；Beta 结束数据清空。

### F. 上线日（11-05）
- [ ] 约 07:00 北京时间开服，登录 → 用预留名建角色 → 开始练级。
- [ ] 首个团本层级 12 月解锁，可提前规划满级路线。

## 四、配置要求（Windows，来源：暴雪支持 000386366 / 国服商城）

**最低配置**
- 系统：Windows 10 64-bit（2019-05 或之后更新）
- CPU：4 核 3.0GHz（Intel Haswell / AMD Ryzen Zen）
- 显卡：DX12 兼容 4GB GPU（GTX 10 系 / AMD RDNA 1 / Intel Iris Xe2-LPG）
- 内存：8 GB
- 存储：SSD 128GB 可用
- 输入：键鼠

**推荐配置**
- 系统：Windows 11
- CPU：8 性能核 5.2GHz（Intel Core Ultra 2 代 / AMD Ryzen Zen 5）
- 显卡：DX12 兼容 8GB GPU（RTX 40 系 / AMD RDNA 3 / Intel Arc B 系）
- 内存：16 GB
- 存储：SSD 128GB 可用
- 输入：多按键滚轮鼠标

> macOS 亦支持（M2/M4 等，详见暴雪支持文档）。
