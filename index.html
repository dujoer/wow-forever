项目总览

目标：在 2026 年 11 月 5 日（国服全球同步上线） 顺利开玩《魔兽世界》："无限"。 本文档为个人准备台账，所有信息来自 2026-09-18 当日的官方与权威媒体公开资料，临近上线请以官网为准。

一、这到底是什么

  • 官方中文名：《魔兽世界》："无限"（部分媒体译为"永恒"；英文 World of Warcraft: Forever）。
  • 定位：暴雪在 2026 暴雪嘉年华公布的 "Classic+（经典+）"永久分支，与 正式服（Modern）、怀旧服（Classic） 并行存在，是"第三条路"。长线运营、非赛季制。
  • 核心形态：回到经过全面画面升级的原版艾泽拉斯，等级上限锁定 60 级，采用横向扩展（加区域/任务/副本/职业玩法/装备，而非提升等级上限）。剧情设定在 2004 原版第一年附近的分叉平行世界线。
  • 去服务器化：不再有传统独立服务器，改为选择规则集——普通 / PvP / 角色扮演 / 专家模式（Hardcore，一命）。
  • 画面：更新光照、全局光照、水体、实时阴影；可选 HD/SD 角色模型、经典动画还原、官方手柄支持。

  • 因为没有等级缩放，越级刷本效率极低 → 每个本严格在其等级窗口内接满任务打一次，之后不再回头。顺序见上表。

  • 传承点数账号获取，但按角色花费；首发上限 16 点（UI 另有"赛季上限 10"的表述，以实装为准）。

  • 练级派：Well Rested（休息经验获取与上限 ↑）、天赋异禀（第 9 级起每级给天赋点）

  • 无等级缩放 → 越级会大量未命中、被抵抗、被打得更疼、消耗暴增。当下区间不舒服就换区，Forever 新增 1000+ 任务正是为此提供替代路径。

捷径 7：精英与长途任务 —— 就地组队 / 炉石动态管理

  • 精英任务、洞穴护送、抢名怪：看见有人在打同一个目标就直接组队（官方设计意图就是促成这种相遇）。
  • 炉石位置要跟着当前任务走，别长期绑死在一个城。

  • 采矿 / 草药：顺路采，但别为了一个节点大幅绕路（"绕 1 小时专门采"远不如"路过 10 秒采一个"）。
  • 丰收（Bountiful Harvest） 传承天赋提升三采集产量 —— 但会挤占练级流点数。

新传导链：必须吃透

副本图纸（Blueprint）→ 对应专业 → 所需材料 → 玩家需求
  • 高级 Blueprint 由特定副本 BOSS掉落，可以形成稀缺加工位。
  • 但不要预设所有图纸都值钱：优先盯"玩家真的想要的那件东西"所需材料。
  • 交易前先在 Beta 确认物品可否交易（部分服务端设为绑定则 AH 倒卖不成立）。

AH 实操原则（新服特征：有需求但玩家手里没钱）

情形做法
常见材料走得快直接卖，保持金币流动性
原材料价 > 成品价卖原料（别为上升技能点而买贵材料）
成品有明确毛利先小批量试，别一上来量产
恶性压价屯一部分别跟着砸
新图纸突发需求上架前重新核价
  • 低等级材料照样有人买（高等级玩家补专业会回头买低级材料）→ 别全丢商店。
  • 不要盲信"每小时 X 金"的攻略：Forever 实际收益取决于服务器供给、规则集人群、图纸获取情况。

每次游戏的固定循环

  1. 出发前：查 AH 里当前等级区间的贵价材料。
  2. 练级中：采途径节点、捡人形怪布料、顺手剥皮（不做长距离绕路）。
  3. 回城前：用剩余背包位再清一轮附近资源。
  4. 回城后：丢商店杂物、挂材料与 BOE、比较"原料价 vs 成品价"。
  5. 打完副本：检查是否新图纸推高了某种材料需求。

零、先说结论（一句话路线）

C. 天赋配点的四条纪律

  1. 不要照搬经典 / TBC / 巫妖王 / 探索赛季 / 正式服的配点——Forever 改动了排数、位置、效果、武器交互和整个装备环境，名字像不等于机制一样。
  2. 不要按探索赛季的思路配：官方明确萨满坦克这类改造不做，Forever 回归更贴近原版的职业辨识度。

零、官方原话：Forever 的属性盘子长什么样

首席游戏设计师 Kris Zierhut 在暴雪嘉年华《"无限"》深度座谈的 「物品与装备：属性（Items and Gear: Stats）」 幻灯片上，列出的属性是这五项：

幻灯片属性中文（暂译）说明
Hit Chance命中几率近战 / 远程 / 法术三者合并为一项
Crit Chance暴击几率三种暴击同样合并
Weapon Skill武器技能机制保留，但单件装备给的更少
Bonus Healing治疗加成现在附带等值约 1/3 的伤害加成
Expertise精准新属性：降低攻击被闪避 / 招架的几率，面向坦克与近战

Zierhut 的原话口径【官方确认】：

  • "经典属性保留，后续资料片的属性也会引入——但我不打算加韧性（Resilience）。"
  • 命中合并："在经典里它被拆成近战、远程和法术三份，对增强萨、惩戒骑，甚至对想让嘲讽命中的战士来说都很别扭。"合并后一项属性覆盖所有攻击，毒药和陷阱也算在内。
  • 暴击合并：同样的处理方式。混合型专精（同时用物理和法术的职业）受益最大。
  • 武器技能：Zierhut 说它在经典里"有点太容易获得、也有点太强"，因此重新平衡——"你不能像以前那样在单件装备上拿那么多，但你还是能拿到。"
  • 治疗加成：经典的痛点是"你出去做任务，根本杀不死东西"，所以每一件治疗装都带伤害加成。
一句话结论：Forever 的属性表没有变复杂，反而因为合并而变简单了；真正的变化在于每一件装备的价值被重新分配——武器技能贬值、治疗装升值、施法者武器升值、饰品专精化、装备开始和"环境与生物类型"挂钩。

三、按"职责"看属性关键（跨职业通用）

3.1 近战物理（战/贼/惩戒骑/增强萨/野德）

顺序：命中（到上限）→ 主属性 → 暴击 → 攻强 → 武器技能/精准 → 耐力 核心变化：

  • 武器技能不再是"必刷品"——官方明确要终结"几件武器技能装永久占位"的局面，单件给的更少。所以别为一把老武器技能装砸冤枉钱，先看清楚它的 Forever 版本。
  • "拿到什么用什么"：官方已取消"唯一正确武器类型"。练级期不要为了武器类型放弃更高秒伤。
  • 精准（降低被闪避/招架） 让近战输出的"实际命中率"更平滑，坦克更稳。
  • 但别急着买：换武器类型会换掉适用的武器技能加成，武器技能仍是一个独立的配装变量。

3.2 远程物理（猎人）

顺序：远程命中到上限 → 敏捷 → 暴击 → 攻强 → 智力 → 耐力

  • 远程判定最"干净"：没有偏斜与闪避，没有实际暴击上限，所以堆命中到 9% 之后，全速堆敏捷与暴击。
  • 近战武器只为属性存在，别为它牺牲远程件。
  • 猎人练级被普遍评为最轻松，但装备依赖度低于战士——这本身就是效率优势。

3.3 法系输出（法/术/暗牧/元素萨/鸟德）

顺序：命中（到上限）→ 法术强度 → 暴击 → 智力 → 耐力 核心变化：

  • 暴击变"通用"：法术暴击与近战暴击合并 → 暴击装的适用面变宽，性价比相对上升。
  • DOT 可暴击（官方改动）→ 持续伤害职业不再"天然不吃暴击"。
  • 施法者武器进入升级序列：10 级起就带法术伤害与治疗 → 武器是法系第一个该评估的部位，别再当"属性棒"。
  • 别只看法术强度：命中没满时，一点命中胜过若干法伤。

3.4 治疗（神圣骑/恢复萨/恢复德/神圣与戒律牧）

顺序：治疗加成 → 智力/精神（续航）→ 暴击 → 耐力；不需要进攻命中 核心变化：

  • 治疗装带约 1/3 的伤害加成（例：官方样张「野性之皮」+42 治疗 / +14 法术伤害，14 ≈ 42÷3）。
  • 所以治疗系不必再养一整套输出装——野外做任务、刷声望、打钱时直接穿治疗装。
  • 但别走到另一个极端：官方与攻略站都提醒不要照搬经典治疗 BIS。纯治疗堆到极致，不如"治疗为主 + 少量伤害/暴击"的混合件。
  • 精神对部分治疗的回蓝价值上升（神圣骑士明确：施法回蓝，精神价值提升）；萨满则多了水盾 / 正念 / 法力之潮三条替代回蓝路径 → 精神的相对权重因职业而异。

3.5 坦克（防战/防骑/熊德）

顺序：耐力 → 护甲 → 精准（降低被闪避/招架） → 格挡/闪避/招架相关 → 命中（仇恨） → 力量 → 防御技能 核心变化：

  • 新增「精准」类属性直指坦克的痛点：降低被闪避 / 招架的几率 → 仇恨生成更稳定。
  • 命中对坦克的价值上升：官方点名"想让嘲讽命中的战士"——嘲讽不中 = 团灭风险。
  • 防御技能、抗性仍保留（经典属性不删）。
  • 圣骑士的坦克工具箱被专门补齐（新坦克圣印、审判嘲讽、10 码嘲讽距离、奉献对前 4 目标高伤以防一次拉满）→ 防骑从"能凑合"变成"正经主坦"。

零、直接回答：真·"一键输出"做不到，而且不是 Forever 才做不到

先把结论说死：

你想要的东西能不能做到原因
点一下，自动按最优循环打完整个战斗❌ 做不到暴雪的宏系统没有变量、没有循环、没有 if 判断，这是 2006 年"安全执行（Secure Execution）"改造后就封死的，与版本无关
点一下，施放"当前优先级最高且可用"的那个技能✅ 能做到（最接近的形态）/cast 多技能排队会跳过不可用的
插件告诉你"下一个该按什么"⚠️ 被严格限制Forever 采用现代（Midnight）战斗 API 限制 + 秘密值（secret values） 机制
外部软件 / 硬件宏替你连续按键🚫 违规，会封号属于自动化，暴雪明令禁止
一句话：Forever 里你能得到的最好结果，是"一个键 = 施放优先级最高的可用技能"，外加官方内置的伤害统计、冷却管理器与即将到来的挥砍计时器。任何声称"一键自动循环"的方案，要么是骗人的，要么会赔上你的账号。

一、宏系统的四条硬限制（20 年没变）

这一节的结论跨所有版本稳定，包括 Forever【机制事实】。

限制具体表现后果
① 没有变量与循环宏里不能存值、不能计数、不能 while/for无法写"循环" —— 这是"一键循环"根本不存在的根本原因
② 没有 if / then 分支只能使用静态可解析的 [条件] 前缀（目标、形态、姿态、战斗状态、修饰键等），且条件在施法前一次性求值无法根据"这个 buff 还剩 3 秒"来决策
③ 一次按键受公共冷却约束每成功施放一个技能就进入 GCD宏不会替你压缩时间，连点也不能突破 GCD
④ 宏读不到战斗数据不能读取敌方施法、不能读取战斗日志事件、不能读取冷却剩余时间做分支无法做"智能优先级"

由此推出的关键行为（决定你该怎么写宏）

/cast 多技能 = 优先级列表，不是循环。 系统会从上往下尝试，施放第一个能用的（不在冷却、资源够、条件满足）。这不是循环，每次按键都是一次全新的从上往下扫描。

#showtooltip
/startattack
/cast 技能A
/cast 技能B
/cast 技能C

行为：A 可用就放 A（B、C 因 GCD 不执行）；A 不可用则试 B；B 不可用则试 C。这就是 WoW 里"一键宏"的真实形态。

二、三种合法形态（这就是上限了）

形态 1：优先级兜底宏（最实用，练级首选）

#showtooltip
/startattack
/cast 嗜血
/cast 旋风斩
/cast 英勇打击
  • 用途：练级、五人本、日常。点一下 = 打当前最优可用技能。
  • 优点：不浪费 GCD、不会空放、单手可操作。
  • 缺点：没有"什么时候该续 DOT / 该不该开爆发"的判断——这部分永远需要你本人。

形态 2：顺序宏（/castsequence）

#showtooltip
/castsequence reset=combat/target 技能A, 技能B, 技能C
  • reset= 只能按"时间 / 换目标 / 脱离战斗"重置，不能按战斗状态重置。
  • 更适合：起手固定序列（如"标记 → DOT → 主输出"）或治疗的多级法术（低等级技能救急）。
  • ⚠️ 练级期反而降低效率：野外战况多变，固定顺序会卡在"技能 B 用不上"的死循环里。优先用形态 1。

形态 3：条件宏（一键两用，节省动作条）

#showtooltip
/cast [mod:shift] 技能B; 技能A          -- 平时A，按Shift放B
/cast [harm] 技能X                      -- 目标敌对才放
/use [target=focus] 技能Y               -- 对焦点目标使用
/cast [@mouseover,help] 治疗技能        -- 治疗用：鼠标悬停目标
  • 用途：把两三个功能压进一个键位；治疗职业几乎必用 [@mouseover,help]。
  • 注意：条件是静态白名单，不是表达式。写不出"如果法力低于 30%"这类判断。

常用零碎但收益高的写法

写法用途
/startattack近战第一行必备：防止平砍中断（换目标、技能失败都会断平砍）
#showtooltip让图标与提示随宏内容变化
/use 13 /use 14使用饰品（两件饰品可写进同一个宏，按可用性依次触发）
/cast [nomod] A; [mod:alt] B同键两用
/targetenemy / /cleartarget清理目标选择
附魔/饰品这类"主动性增益"建议单列一个键，而不是塞进输出宏——因为你需要决定什么时候开，而不是让它一到 CD 就自动开。

三、Forever 的额外限制：连"插件提示"也被堵了

这是 Forever 与经典怀旧服最大的不同，也是必须先搞清的前提。

3.1 官方原话：用的是"现代 API"【官方确认】

首席软件工程师 Nora Mills 在开发者问答中，被直接问到"Forever 用的是 Midnight 的插件限制、经典 API，还是别的"时回答：

"我们选择了现代 API 方案。"

她给了三条理由与两条承诺：

类别内容
理由①对插件开发者有同理心——现代 WoW 与 Forever 共用一套 API 更容易维护
理由②Forever 的首领战比现代版简化得多，所以战斗限制不该负面影响体验
理由③不希望玩家"觉得必须装插件才能玩"——那会导致门槛与"守门"
承诺①随游戏内置伤害统计 + 冷却管理器
承诺②"挥砍计时器（Swing Timer）可能即将推出"

另据官方 UI 频道：Forever 与主分支共用界面架构，包含 12.1.5 的绝大部分 API；12.1.0 引入的 AuraContainer / AuraButton 改动同样可用；Midnight 的插件限制（含"秘密值"）在 Forever 同样生效。

3.2 "秘密值（secret values）"是什么意思

这是理解一切的关键【第三方实测，机制描述准确】：

插件被允许"显示那个盒子、调整它的大小、把它挪个位置"，但被禁止"打开盒子、用里面的内容做决定"。

落到实操上：

能做不能做
显示你自己的 buff / debuff / 冷却 / 资源读取敌方施法条来判断"该打断了"
显示你自己的持续时间与层数读取战斗日志事件来推算接下来的最优动作
UI 定制（动作条、框体、字体、背包、地图、拍卖行）读取战斗中其他玩家的状态来发指令
首领模组的基础计时（DBM / BigWigs 在正式服同限制下可运行）"计算并给出结论" 类功能——被明确限制

直接后果：

  • Hekili 式"下一个技能"提示按原方式做不出来——它需要读取冷却/资源/敌方状态去跑优先级，属于被限制的"计算"类别。
  • WeakAuras 仍然存在，但只能做"关于你自己的"那部分（buff、冷却、资源）。
  • Classic / Era 插件不能直接加载 → 需要 Forever 专用版本（Questie、Bagnon、拍卖行、大型 UI 套件已有作者在移植）。
  • Details / Recount 变成可选——因为官方内置伤害统计才是人人都有的那一个。

3.3 官方为什么这么做（理解它，就不会走弯路）

官方口径非常一致："插件应该帮你看见游戏，而不是替你玩一部分游戏。" 再加上 Forever 刻意追求"没有被解完的艾泽拉斯"——限制计算型插件，正是为了让首领机制在第一周保持未知。

四、官方给你的三条替代路径

既然宏做不了循环、插件又不能替你算，Forever 把原本靠外部工具补齐的部分做进了游戏里：

内置功能状态对谁最重要

六、效率工具（Forever 版本修正）

⚠️ 已确认（9-19 第三次更正，请以本次为准）：官方开发者问答中，首席软件工程师 Nora Mills 被直接问到"Forever 用 Midnight 的插件限制、经典 API，还是别的"，明确回答： "我们选择了现代 API 方案。" 官方同期补充：Forever 与主分支共用界面架构，包含 12.1.5 的绝大部分 API；Midnight 的插件限制（含"秘密值 secret values"）在 Forever 同样生效。 这不是"插件被禁"，而是"插件不能替你算"：插件仍可显示你自己的 buff / 冷却 / 资源、仍可做界面与背包定制，但读取敌方施法条、战斗日志事件、战斗中其他玩家状态来推导该按什么——这类"计算型"功能被限制。 修正记录：此前本文件写"WeakAuras / Hekili 不可用"，不够准确。实际是 WeakAuras 仍然存在（受同一战斗限制，只能做"关于你自己"的部分）；Hekili 式"下一个技能"提示按原方式确实做不出来（它需要读取冷却/资源/敌方状态去计算，属于被限制的类别）。 当前策略：优先依赖官方原生功能；不要现在就整理"必装插件清单"，等适配新接口的版本出现后再定。宏与插件的详细边界见 macros-and-ui.md。 官方原生已带（可在无插件情况下用）：内置伤害统计、冷却管理器（均已确认随游戏发布）、优化后的任务追踪、更清晰的姓名板、焦点目标，以及全面更新的现代风格 UI。 官方称"即将推出"：挥砍计时器（Swing Timer） —— 对依赖自动攻击节奏的圣印舞骑士与增强萨意义重大。 修正记录：此前本文件写"冷却管理器是计划中而非首发"，该说法已被推翻——Mills 原话是 Forever "ships with a built-in damage meter and cooldown manager"。 官方明确没有：原生不带法术报警类功能，插件系统仍开放。
